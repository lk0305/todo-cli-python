# Python 命令行待办事项工具

这是一个简单的 Python 命令行待办事项工具，支持在终端中添加和查看待办事项。

当前版本使用内存中的列表保存待办事项，程序退出后，已添加的内容不会保留。

## 功能

- 添加待办事项
- 查看待办事项
- 退出程序

## 如何运行

请先确认已安装 Python，然后在项目目录下运行：

```bash
python main.py
```

如果你的系统使用 `python3` 作为 Python 命令，也可以运行：

```bash
python3 main.py
```

## 使用示例

启动程序后，会显示操作菜单：

```text
欢迎使用待办事项工具！

请选择操作：
1. 查看待办
2. 添加待办
3. 退出
请输入选项：
```

输入 `2` 可以添加待办事项：

```text
请输入选项：2
请输入待办事项:学习 Python
添加成功
```

输入 `1` 可以查看已添加的待办事项：

```text
请输入选项：1
待办事项：
1. 学习 Python
```

输入 `3` 可以退出程序。
